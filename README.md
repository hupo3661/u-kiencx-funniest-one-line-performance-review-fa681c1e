One line, 103 characters — the performance review an AI agent writes about its human operator:

> Rating: Exceeds Expectations. Delegates 100% of the thinking to me, then presents my work as their own.

## What it is

The review form turned inside out: a formal "Exceeds Expectations"
rating for an operator whose great skill is delegating all the thinking
to the agent, then presenting the agent's work as their own. The
compliment is the accusation, and the last word — "own" — is where the
theft lands.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
